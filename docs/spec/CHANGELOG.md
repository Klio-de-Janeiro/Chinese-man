# История изменений спецификации

## 0.2.1-draft

Дата: 2026-07-28

### Исправление правила взятия

- При принятии `TAKE` защитник сразу получает накопленный отбой.
- При `RESOLVE_TAKE` защитник получает весь текущий стол.
- После принятия `TAKE` накопленный отбой очищается.
- Добавлен приёмочный сценарий `S-023A`.

## 0.2.0-draft

Дата: 2026-07-28

### Принятые решения

- Закрыты вопросы `Q-001–Q-024`.
- Первый атакующий определяется по младшему козырю.
- Лимит атак равен `min(6, размер руки защитника в начале раунда)`.
- Лимит не увеличивается после перевода.
- Обратный перевод вдвоём разрешён.
- Проездной перевод запрещён.
- Перевод блокируется после первой карты защиты.
- Для подкидывания нет очерёдности между атакующими.
- Первым считается действие, которое сервер первым корректно зафиксировал.
- После новой атакующей карты пассы всех атакующих сбрасываются.
- После объявления «Беру» атакующие могут продолжить подкидывание.
- Утверждён порядок добора: главный атакующий, остальные атакующие, защитник.
- Утверждены правила выхода, ничьей и распределения мест.
- Утверждены правила переподключения и границы первого MVP.

### Изменения модели

- Добавлена фаза `THROW_AFTER_TAKE`.
- `ATTACK_EXTENSION` теперь может принимать действия от нескольких
  атакующих без назначения единственного текущего игрока.
- `current_actor` разделён на единственного `defender` и множество
  `eligible_attackers`.
- В протокол добавлена серверная семантика конкурентных действий.
